# Clashcade — publicação

Este repositório contém **só o site pronto** (pasta `site/`), publicado pela Cloudflare a cada push na `main`.
Cada commit é uma versão publicada; para voltar, use o "rollback" de implantações na Cloudflare ou republique uma
versão anterior a partir do repositório de código.

O código-fonte, a documentação e os backups ficam em repositório privado. Não edite nada aqui: tudo é gerado.
